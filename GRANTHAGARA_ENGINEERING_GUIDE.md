### The Fundamental Rule: "Spatial 3D WebGL Canvas + 2D DOM Folio Spread"
Many 3D web experiments fail when developers attempt to render long-form body text directly onto 3D WebGL textures or canvas sprites:
1. **DPI Degradation:** Text rendered into WebGL canvas textures blurs or aliases heavily on non-standard device pixel ratios (Retina, mobile screens).
2. **Accessibility Failure:** 3D text cannot be highlighted, natively selected, copied to clipboard, or inspected by screen readers.
3. **VRAM Exhaustion:** Creating unique high-resolution texture maps for hundreds of text pages consumes hundreds of megabytes of GPU texture memory, triggering browser tab crashes.

## 2. Origins, Lineage & Reverse Engineering

### 2.1 Lineage 1: Scroll Storytelling Architecture
The application employs an advanced scroll narrative technique where the visual background and hero stage remain pinned in place (`position: sticky`), while the textual narrative seamlessly transforms as the user scrolls.

Granthāgāra adapts this pattern in `HeroScrollStage.tsx` and `HeroScrollStage.module.css`:
1. **Pinned Hero Stage:**
   ```css
   .hero {
     --hero-progress: 0;
     position: relative;
     min-height: calc(max(100svh, 720px) + min(65svh, 600px));
   }
   .stage {
     position: sticky;
     top: 0;
     height: 100svh;
     overflow: hidden;
     isolation: isolate;
   }
   ```
2. **Scroll Progress Interpolation & Cross-Fade:**
   As the user scrolls down, a normalized value $p \in [0, 1]$ is computed:
   $$p = \text{clamp}\left(0, \frac{\text{window.scrollY} - \text{heroTop}}{\text{trackDistance}}, 1\right)$$
   For mobile touch devices, fluid exponential smoothing prevents stutter:
   $$p_{\text{smooth}}(t) = p_{\text{smooth}}(t - \Delta t) + (p_{\text{raw}} - p_{\text{smooth}}(t - \Delta t)) \cdot \left(1 - e^{-\Delta t / 80}\right)$$
3. **Typography Transformation:**
   - **Intro Text (Nasadiya Sukta):** Fades out and ascends slightly:
     $$\text{transform} = \text{translateY}(-75px \cdot p), \quad \text{opacity} = \text{clamp}(0, 1 - 2.3p, 1)$$
   - **Arrival Text (Ekam Sat):** Cross-fades into focus:
     $$\text{transform} = \text{translateY}(55px \cdot (1 - p)), \quad \text{opacity} = \text{clamp}(0, 2.2(p - 0.36), 1)$$
   - The visual backdrop (Maa Saraswati artwork or Vedic Dawn canvas) remains rock-solid while the headline transforms from cosmic void to illuminated wisdom.

### 2.2 Lineage 2: Spatial Craftsmanship from `library.jjangik.kr`

### 2.3 The 10 Hidden Architectural Secrets of Production 3D Libraries

#### Secret 1: "The Room is a Lie" (The 2D/3D Hybrid Stage Set)
- *The Trap:* Modeling a complete 3D room with 6 walls, ceiling, exterior landscape, and window mesh. This creates dozens of draw calls, light leaking, shadow depth artifacts, and poor mobile frame rates.
- *The Solution:* The room is a theatrical stage set:
  1. A dark walnut window frame at $X = -7.2, Y = 0.65, Z = 0.2$ with sill, lintel, and mullions.
  2. A 2D atmospheric backdrop plane at $Z = -0.28$ (behind the frame) with a procedural sky gradient and 55 starlight points.
  3. An emissive moon quad at $Z = -0.22$ with `emissiveIntensity = 2.2`.
  4. Natural optical parallax: As the camera pans horizontally, the spatial gap between $Z = 0.2$, $Z = -0.22$, and $Z = -0.28$ generates depth without 3D geometry overhead.

#### Secret 2: Procedural Texture Synthesis (Zero Network Latency)
All wood grain, Moroccan leather, book spines, paper edges, sky backdrops, and stone tiles are synthesized in-memory via HTML5 Offscreen Canvases using trigonometric and noise algorithms. This guarantees zero network texture loading delays and instant interactive startup.

#### Secret 3: Maximum GPU Anisotropic Filtering
Standard WebGL mipmaps aggressively blur textures viewed at oblique, glancing angles (such as looking down a shelf row). Granthāgāra queries the hardware limit and clamps anisotropy to 16:
```typescript
const maxAnisotropy = renderer.capabilities.getMaxAnisotropy();
texture.anisotropy = Math.min(maxAnisotropy, 16);
texture.minFilter = THREE.LinearMipmapLinearFilter;
texture.generateMipmaps = true;
```

#### Secret 4: Single-Book Isolated Hover Elevation
Rather than displacing neighboring books with a Gaussian bell curve, hover math isolates exclusively the book under the pointer. The targeted codex slides forward ($Z = +0.52$), lifts up ($Y = +0.085$), and tilts forward ($\text{RotX} = -0.045\text{ rad}$), leaving all shelf neighbors seated firmly in place.

#### Secret 5: GSAP Ticker Synchronization & Page Visibility
Never run unmanaged `requestAnimationFrame` loops in complex React applications. Tying Three.js rendering to `gsap.ticker.add` locks 3D mesh tweens and WebGL draws to the same clock, eliminating micro-stutters. Halting the loop via the Page Visibility API (`document.visibilitychange`) prevents battery drain on hidden tabs.

#### Secret 6: Damped Harmonic Oscillator (Spring Physics)
The hanging pendant lamp in the sanctum center does not rotate on scripted keyframes. It is governed by a second-order spring differential equation ($a = -k\theta - dv + \text{impulse}$), reacting dynamically to mouse sweeps and pull-cord clicks.

#### Secret 7: Continuous Mechanical Clock Kinematics
The analog library clock calculates hand angles continuously using millisecond precision ($(\text{seconds} + \text{ms}/1000) / 60$), allowing the second hand to glide like a precision escapement rather than jumping rigidly once per second.

#### Secret 8: The "Anti-Sharp" Rule (Beveled Geometry)
Standard 90° sharp cubes look synthetic because razor edges cannot catch specular highlights. Every visible hero mesh (books, shelves, pillars, cornices) utilizes `RoundedBoxGeometry` with a subtle bevel radius ($0.012 - 0.018$ units) to capture ambient light reflections.

#### Secret 9: Dual-Tone Cinematography Lighting
Visual warmth stems from chromatic contrast: a warm amber-peach spotlight (`#ffc994`, 4.2 intensity) and diya flames (`#ff9e38`) balanced against cool silvery moonlight (`#7f9fd6`, 1.8 intensity), resolved through `ACESFilmicToneMapping` with an exposure of 1.08.

#### Secret 10: Zero-Asset Web Audio API Procedural Synthesis
Sound effects for paper rustle, book slides, singing bowl chimes, and pull-chain clicks require zero downloaded `.mp3` or `.wav` files. All audio is synthesized in real time via filtered pink noise and frequency-modulated oscillators, randomized between 0.96 and 1.04 pitch to eradicate acoustic fatigue.

### 3.4 Why Book Flight and Sliding Sounds Were Muted
Early builds triggered a wooden friction scrape during book flight from shelf to camera. User instructions explicitly requested a **serene, contemplative atmosphere**. 

Auditory analysis showed that playing mechanical sliding sounds during camera zoom and book extraction broke the reverent mood of a sacred library. The engine was updated to **mute all book flight and sliding audio**, reserving sound strictly for:
1. Delicate parchment leaf turning (`playPageTurn`).
2. Celestial singing bowl tone upon opening (`playBookOpenChime`).
3. Tactile brass pull-chain click on lamp light toggle (`playLampClick`).

## 7. Single-Book Isolated Hover Elevation

### 7.1 Mathematical Comparison: Gaussian Swell Curve vs. Target Isolation

#### The Gaussian Swell Approach:
$$\Delta Z(x) = A \cdot \exp\left( -\left(\frac{x - x_{\text{cursor}}}{K}\right)^2 \right)$$
where $A$ is peak lift amplitude and $K$ is the influence radius constant.

#### The Target Isolation Approach:
$$\Delta Z_i = \begin{cases} 
0.52 & \text{if mesh } i \text{ is intersected by the raycaster} \\ 
0.00 & \text{otherwise} 
\end{cases}$$

### 7.2 Why Gaussian Swell Math Failed on Bookshelves
Applying a Gaussian bell curve to books on a shelf resulted in severe artifacts:
1. **Adjacent Book Collision:** Books have finite thickness. Elevating neighbors along $+Z$ and $+Y$ simultaneously caused adjacent book geometries to clip into one another.
2. **Ceiling Board Clipping:** As neighboring books rose along $+Y$, their top corners collided with the upper shelf plank.
3. **Selection Ambiguity:** The user could not immediately discern which book was targeted for extraction when 3 or 4 adjacent codices moved at once.

### 7.3 Exact Target Offsets & Exponential Kinematic Damping
Granthāgāra enforces **Strict Target Isolation**: only the codex directly under the pointer moves.

```typescript
this.bookMeshes.forEach(mesh => {
  const data = mesh.userData as BookMeshUserData;
  const isThisHovered = (hoveredMeshTarget === mesh);

  // Exact target kinematic transformations
  const targetOffset = isThisHovered ? 0.52 : 0;   // Slides forward along +Z
  const targetYLift  = isThisHovered ? 0.085 : 0;  // Lifts up along +Y
  const targetRotX   = isThisHovered ? -0.045 : 0; // Tilts forward slightly

  // Exponential damping toward target (0.18 per frame)
  data.hoverOffset += (targetOffset - data.hoverOffset) * 0.18;
  data.currentYLift  += (targetYLift  - data.currentYLift)  * 0.18;
  data.currentRotX   += (targetRotX   - data.currentRotX)   * 0.18;

  mesh.position.z = data.basePos.z + data.hoverOffset;
  mesh.position.y = data.basePos.y + data.currentYLift;
  mesh.rotation.x = data.baseRot.x + data.currentRotX;
});
```

### 7.4 The Deliberate Role of Gaussian Swell in 2D UI (Index Lens)
While Gaussian swell math failed on 3D shelves, it functions smoothly in 2D UI lists. Granthāgāra utilizes Gaussian mathematics in:
1. `IndexLensDrawer.tsx`: Quick-navigation title directory ($K = 1.6$).
2. `InteractiveBookReader.tsx` (`GaussianLineLens`): Hovering over Sanskrit shloka lines ($K = 1.45$):
   $$\text{intensity}(d) = \exp\left( -\left(\frac{d}{K}\right)^2 \right)$$
   $$\text{scale} = 1 + \text{intensity} \cdot 0.08, \quad y_{\text{offset}} = \text{sign}(d) \cdot \text{intensity} \cdot 3.2\text{px}$$
   The line under the cursor magnifies while adjacent lines step aside smoothly, enabling precise recitation tracking.

## 10. Physicality, Kinematics & The "Anti-Sharp" Rule

### 10.1 Hanging Pendant Lamp Damped Harmonic Spring Physics
The brass pendant lamp is anchored to a ceiling pivot at $(0, 4.9, 0.7)$ and governed by a second-order harmonic oscillator:

$$\begin{aligned}
a_z &= -k \cdot \theta_z - d \cdot v_z + \text{impulse}_z \\
a_x &= -k \cdot \theta_x - d \cdot v_x + \text{impulse}_x
\end{aligned}$$

Where:
- $k = 0.055$ (Spring stiffness restoring torque).
- $d = 0.045$ (Frictional damping coefficient).
- $\text{impulse} = \text{mouse delta velocity or pull-chain jerk}$.

```typescript
// Render Tick Spring Physics Update
const impulseZ = this.lerpedMouse.x * 0.003;
const impulseX = -this.lerpedMouse.y * 0.002;

const accelZ = -this.lampSpringK * this.lampAngleZ - this.lampDamping * this.lampVelZ + impulseZ;
const accelX = -this.lampSpringK * this.lampAngleX - this.lampDamping * this.lampVelX + impulseX;

this.lampVelZ += accelZ;
this.lampVelX += accelX;

this.lampAngleZ += this.lampVelZ;
this.lampAngleX += this.lampVelX;

this.lampPivotGroup.rotation.z = this.lampAngleZ;
this.lampPivotGroup.rotation.x = this.lampAngleX;

// Synchronize SpotLight with swinging bulb position and direction
if (this.bulbMesh && this.lampSpot) {
  this.bulbMesh.getWorldPosition(this.lampSpot.position);
  this.lampSpot.target.position.set(
    this.lampSpot.position.x + Math.sin(this.lampAngleZ) * 3.5,
    0.0,
    this.lampSpot.position.z + Math.sin(this.lampAngleX) * 3.5
  );
}
```

#### Interactive Chain Pull Impulse:
Clicking the shade, bulb, or brass acorn pull cord triggers:
1. Metallic click audio (`playLampClick`).
2. Downward jerk impulse: `lampVelX += 0.055; lampVelZ += (Math.random() - 0.5) * 0.045;`.
3. GSAP smooth transition of spotlight intensity ($4.2 \leftrightarrow 0.0$) and center room glow.

### 10.2 Continuous Mechanical Library Clock Kinematics
Located on Tier 0 at $X = 4.0, Y = 1.52, Z = 0.25$, the analog clock calculates continuous angles to avoid stepped ticking jitter:

$$\begin{aligned}
\theta_{\text{sec}} &= -\left(\frac{\text{seconds} + \text{milliseconds}/1000}{60}\right) \cdot 2\pi \\
\theta_{\text{min}} &= -\left(\frac{\text{minutes} + \text{secProgress}}{60}\right) \cdot 2\pi \\
\theta_{\text{hour}} &= -\left(\frac{(\text{hours}\bmod 12) + \text{minProgress}}{12}\right) \cdot 2\pi
\end{aligned}$$

Hands rotate around centered base-anchored pivots within a brass bezel and 12 classical hour indices.

### 10.3 The "Anti-Sharp" Rule: `RoundedBoxGeometry` & Specular Rim Catches
In physical reality, zero-radius 90-degree edges do not exist. In computer graphics, standard sharp-edged boxes look artificial because their infinitesimal edges cannot catch light reflections.

Granthāgāra builds all visible solid objects with `RoundedBoxGeometry`:
- **Books:** `width = bookThickness, height = bookHeight, depth = bookWidth, segments = 3, radius = 0.012`.
- **Bookshelf Planks:** `radius = 0.012, segments = 2`.
- **Fluted Pillars & Cornices:** `radius = 0.015, segments = 2`.
- **Bookends & Frame Mounts:** `radius = 0.008 - 0.010, segments = 2`.

These micro-bevels catch specular highlights from the pendant spotlight and oil flames, imparting tangible physical mass to wooden and leather objects.

```typescript
public calculateAdaptiveCameraFit(): { fov: number; z: number } {
  const width = this.container?.clientWidth || window.innerWidth;
  const height = this.container?.clientHeight || window.innerHeight;
  const aspect = width / height;

  // Adaptive Field of View
  let fov = 27;
  if (aspect < 0.7) {
    fov = 35; // Mobile portrait
  } else if (aspect < 1.0) {
    fov = 31; // Tablet / foldable
  } else if (aspect > 2.2) {
    fov = 28; // Ultrawide desktop
  } else {
    fov = 27; // Standard desktop
  }

  const vFovRad = (fov * Math.PI) / 180;
  const halfFovTan = Math.tan(vFovRad * 0.5);

  const targetHeight = 6.5;
  const targetWidth = aspect < 1.0 ? 9.6 : 14.8;

  const zFromHeight = (targetHeight * 0.5) / halfFovTan;
  const zFromWidth = (targetWidth * 0.5) / (halfFovTan * aspect);

  let z = Math.max(zFromHeight, zFromWidth) + 0.6;
  if (aspect < 1.0) {
    // Clamped range on mobile for comfortable touch targets
    z = Math.min(Math.max(z, 15.0), 20.0);
  }

  return { fov, z };
}
```

## 12. Shadows & Depth Engineering

### 12.1 PCFSoftShadowMap & Penumbra Filtering
Granthāgāra employs Percentage-Closer Soft Shadows (`THREE.PCFSoftShadowMap`):
```typescript

this.renderer.shadowMap.type = THREE.PCFSoftShadowMap;
```
PCFSoftShadowMap performs multiple depth texture lookups with jittered offsets, producing a realistic penumbra blur where shadows soften naturally as distance from the occluder increases.

### 12.2 Contact Shadows & Ambient Occlusion via Gaps & Edge Darkening
Real-time screenspace ambient occlusion (SSAO) post-processing passes can drop mobile frame rates below 30fps. Granthāgāra achieves studio-grade contact shadows and ambient occlusion with zero post-processing overhead:
1. **Geometric Crevice AO:** Gaps between `RoundedBoxGeometry` book meshes and shelf planks trap directional light, creating natural geometric shadow crevices.
2. **Procedural Texture Edge Darkening:** In `createSpineTexture()`, spine edges are shaded darker:
   ```typescript
   baseGrad.addColorStop(0.0, this.shadeColor(book.spineColor, -50));
   baseGrad.addColorStop(1.0, this.shadeColor(book.spineColor, -55));
   ```

   When books stand row-by-row on a shelf, these darkened edges produce deep contact shadow seams between adjacent codices.
3. **Plank Seam Grooves:** In `createBackboardWoodTexture()`, 4px deep black grooves (`rgba(10, 5, 2, 0.85)`) simulate ambient occlusion between tongue-and-groove timber boards.

### 12.4 Shadow Bias Optimization (Eliminating Acne & Peter Panning)
Configuring directional shadow maps on dense geometry presents two hazards:
1. **Shadow Acne:** Setting `shadow.bias = 0` causes self-shadowing moiré stripes and dark banding across planar surfaces like shelves.
2. **Peter Panning:** Over-correcting with positive bias (`bias = 0.01`) causes shadow detachment, making books appear to float above the shelf.

Granthāgāra resolves this balance using coupled negative bias and positive normal bias:
```typescript
// Overhead Key Directional Light
keyLight.shadow.mapSize.width = 2048;
keyLight.shadow.mapSize.height = 2048;
keyLight.shadow.bias = -0.00025;      // Slightly pulls depth comparison inward
keyLight.shadow.normalBias = 0.02;    // Offsets sample along mesh surface normal
keyLight.shadow.radius = 2.0;

// Pendant SpotLight
this.lampSpot.shadow.mapSize.width = 1024;
this.lampSpot.shadow.mapSize.height = 1024;
this.lampSpot.shadow.bias = -0.0002;
this.lampSpot.shadow.normalBias = 0.015;
this.lampSpot.shadow.radius = 2.0;
```
This configuration eliminates shadow acne completely while keeping book bases firmly anchored to the wooden shelf base.

## 13. Strict GPU Memory Hygiene & Anti-Crash Protocol

Single-page React applications that mount and unmount WebGL scenes often suffer from runaway GPU memory leaks. Simply removing the `<canvas>` DOM element does not deallocate compiled WebGL shader programs, buffer geometries, shadow map render targets, or texture buffers from VRAM.

### 13.1 Comprehensive Scene Graph Disposal
When `BookshelfModal` unmounts, `BookshelfScene.destroy()` executes a recursive traversal:

```typescript
public destroy() {
  // 1. Detach GSAP ticker & visibility listeners
  gsap.ticker.remove(this.tickerCallback);
  document.removeEventListener('visibilitychange', this.visibilityHandler);

  // 2. Kill all active GSAP tweens on meshes, camera, and lights
  this.bookMeshes.forEach(mesh => {
    gsap.killTweensOf(mesh.position);
    gsap.killTweensOf(mesh.rotation);
  });
  gsap.killTweensOf(this.camera.position);
  gsap.killTweensOf(this.shelfGroup.rotation);
  gsap.killTweensOf(this.lampSpot);
  gsap.killTweensOf(this.centerGlow);

  // 3. Recursive Scene Graph VRAM Disposal
  this.scene.traverse((obj) => {
    if (obj instanceof THREE.Mesh || obj instanceof THREE.Points) {
      if (obj.geometry) {
        obj.geometry.dispose();
      }
      if (obj.material) {
        if (Array.isArray(obj.material)) {
          obj.material.forEach((mat) => this.disposeMaterial(mat));
        } else {
          this.disposeMaterial(obj.material);
        }
      }
    } else if ('shadow' in obj && (obj as any).shadow?.map) {
      (obj as any).shadow.map.dispose();
    }
  });

  // 4. Destroy Modular Components
  if (this.sanctumFloor) {
    this.sanctumFloor.destroy();
    this.sanctumFloor = null;
  }

  // 5. Purge CanvasTexture Cache
  BookTextureFactory.disposeAll();

  // 6. Clear Scene Collections
  this.scene.clear();
  this.bookMeshes.length = 0;
  this.bookMeshMap.clear();
  this.diyaLights.length = 0;
  this.particles = null;

  // 7. Remove Canvas & Dispose WebGLRenderer
  if (this.container && this.renderer.domElement.parentNode === this.container) {
    this.container.removeChild(this.renderer.domElement);
  }
  this.renderer.dispose();
}

private disposeMaterial(mat: THREE.Material) {
  const m = mat as any;
  for (const key in m) {
    const val = m[key];
    if (val && typeof val === 'object' && val.isTexture) {
      val.dispose();
    }
  }
  mat.dispose();
}
```

To prevent memory leaks from retained closures, all DOM event handlers (`mousemove`, `mousedown`, `mouseup`, `click`, `resize`) are bound once and stored in class fields for clean removal via `removeEventListener`.
